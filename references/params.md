# 参数总表

改这些值前先想清楚影响面：`budget`/`line_spacing` 会改变行数，而行数是「文字区/图形区」分界的输入。

## 一、手写渲染（`scripts/lib/api.py` `render()`）

| 参数 | 默认 | 说明 |
|---|---|---|
| `font` | `一号字体` = `青叶手写体.ttf` | 只有一号/二号两档，别名由 `api.resolve_font()` 换成真实 ttf |
| `font_size` | 106 | 画布 2481 宽下约 9mm；建议 ≥100 |
| `line_spacing` | 176 | 行距；必须大于 `font_size` |
| `margin` | `[150,150,110,110]` | 上/下/左/右 |
| `page_w` / `page_h` | 2481 / 3507 | A4 @300dpi；两个必须同时传 |
| `wide_no_fig` | true | 无图题改用加宽画布（见 `page_w_wide`），只放宽不改字号 |
| `wide_ratio` | 1.29 | 宽画布 = `page_w × 该系数`（2481 → 3200） |
| `page_w_wide` | 3200 | 派生值，别手写；无图题的画布宽 |
| `budget_wide` | 27.1 | 派生值，别手写；= (page_w_wide − 左右边距) ÷ 字号 − 1 |
| `line_spacing_sigma` | 0 | **不要改**，行距抖动会破坏行基准线 |
| `font_size_sigma` / `word_spacing_sigma` | 2 / 2 | 字号、字距的轻微扰动 |
| `perturb_x/y_sigma` | 3 / 3 | 每个字的位移抖动 |
| `perturb_theta_sigma` | 0.04 | 字的旋转抖动 |
| `strikethrough_probability` | 0 | **必须 0**，否则随机出现「划掉的错字」 |
| `isUnderlined` | true | 每行画 1px 黑线，兼作行基准线；拆块时会剔除 |
| `preview` / `full_preview` | true / false | 决定结果返回 JSON+base64 还是 zip |
| 轮询 | 2s ×N，总超时 300s | 队列满按 `estimated_wait_seconds` 退避 |

## 二、折行（`scripts/lib/textwrap.py`）

| 参数 | 默认 | 说明 |
|---|---|---|
| `budget` | 17.0 | 每行显示宽度（中文按 1.0 计）；**有图题**用它 |
| `budget_wide` | ≈27 | **无图题**用它（按宽画布算），所以一行能多写 ~9 字 |
| `cjk` / `ascii` | 1.0 / 0.67 | 字宽换算。0.67 是实测值：调小（如 0.62）会让折行结果比服务端宽，被二次折行切断英文单词 |
| `mode` | `hard` | `none` 表示不折行（交给服务端自己折） |
| 规则 | — | 标点不放行首、行末不留 `=：（【《`、孤字回借 |

> 服务端会按它自己的排版再折一次。若实际行数比预期多，把 `budget` 调小 0.5 再试。

## 三、标签贴片（`scripts/lib/stage_page.py`）

| 参数 | 默认 | 说明 |
|---|---|---|
| `SHEET_FS` / `SHEET_LS` | 64 / 104 | 标签字条的字号与行距 |
| `LABEL_SHEET_W` | 620 | 字条画布宽 |
| 缩放系数 | `k = size / (SHEET_FS * 0.5)` | 标签字号 → 贴片像素尺寸 |
| `isUnderlined` | false | 标签绝对不能带下划线 |

## 四、拆块（`scripts/lib/stage_extract.py` + `imgfast.py`）

| 参数 | 默认 | 说明 |
|---|---|---|
| `INK` | 176 | 灰度 ≥ 此值算纸白 |
| `SPAN` | 118 | `alpha = (176-lum)/118`，越大笔画越淡 |
| `DARK` | 110 | 判「深色」的阈值（找横线用） |
| 横线判据 | `> 0.80 × 页宽` | 且上下 ±2 行暗像素 < 25%。图形坐标轴只占 50%~67% |
| 文字区上界 | `y_fig = top + 行数×line_spacing + 90` | 行数来自 `wrap()` 的结果 |
| 裁切 pad | 文字 6 / 图形 10 | 包围盒外扩 |

> 实测（2481×3507 整页）：解码 Pillow 0.09s / 纯标准库 2.3s；去线 0.01s；包围盒 0.007s；出 RGBA 0.06s。
> 单页合计 **0.17s**（Pillow）或 **2.6s**（无 Pillow），旧版逐像素写法约 19s/页。

## 五、排版（`scripts/lib/stage_layout.py`）

| 参数 | 默认 | 说明 |
|---|---|---|
| `SMAX` | 0.40 | 多题一页时字号缩放上限（观感约束） |
| `SMAX_ONE` | 0.62 | 一题一页时的上限 |
| `MIN_READ` / `layout.min_scale` | 0.38 | **目标字号**：分页后的统一 s 低于它就多分一页。0.40 在多数版面下不可达（无图题块 ~2900px、纸面可写宽 ~1100px，宽度天花板 ≈0.38） |
| `GAIN_MIN` / `layout.min_gain` | 0.08 | **加页的收益门槛**：多分一页若换来不足 8% 的字号提升就不加。页数也是代价，这条防止「多一页只大 6%」 |
| `SMIN` | 0.30 | **告警线**：统一 s 低于它只打印提示，不再强行放大（放大必然顶出纸边） |
| `SFLOOR` | 0.15 | 绝对地板；再小就不排了，由「单题超页检查」直接报错 |
| `layout.pages` | — | 指定页数，直接按该页数分页，字号反算（`--pages`） |
| `layout.gap_target` | 0.048 | 目标题距 = 该比例 × 页高，±12% 随机抖动；余量留页脚，不硬拉题距 |
| 停止条件 | 达标 or 收益不足，先到先停 | 目标不可达时停在最后一档有正收益的分页，不会一路拆到一题一页（过拐点后 s 反而下降） |
| 全篇字号 | 各页上限的**最小值** | 换纸也统一为同一个缩放（`fit_scale(want=...)` 兜底） |
| 块宽上限 | 有图题 `0.66W` / 无图题 `W` | 无图题用满整幅宽 → 一行写到右边距 |
| `refw` | 只取**有图题**最宽的文字块 | 加宽的无图题块不参与，图列位置不被挤走 |
| 题距 | `0.019H ~ min(gap_target, 0.104H)` | 目标约 1.5 行，带 ±12% 抖动 |
| 图宽上限 | `0.326W` | 按纸面宽度比例 |
| 图列间距 | `0.032W` | 文字列与图列的空隙 |
| 图高上限 | 文字块高 × 1.22（一题一页 1.55） | |
| 出图倍率 | `--scale 1.6` | 纸面 1440×1920 → 2304×3072 |

## 六、纸面（`scripts/lib/paper.py`）

| 参数 | 默认 | 说明 |
|---|---|---|
| `mode` | auto | 检出 ≥3 条长横线才擦；`on` 强制、`off` 不擦 |
| 闭运算半径 | 6 行 | 只吃掉竖直方向 ≤12px 的暗线 |
| 提亮区间 | 2 ~ 120 灰阶 | 太黑的不碰（避免把书脊、污渍当线） |
| 可用区内缩 | 8px | 防止压到纸边 |
| 纸色阈值 | 中位亮度 ×0.6 | 自适应亮纸/暗纸 |
