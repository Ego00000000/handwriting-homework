# 报错对照表

## 环境类

| 现象 | 原因 | 处理 |
|---|---|---|
| `找不到 Edge/Chrome` | 浏览器不在常见路径 | `--edge "C:/.../msedge.exe"` 或设 `EDGE_PATH`；最后会自动列出尝试过的路径 |
| `截图失败（rc=1）` | 页面路径或参数问题 | 用 `--keep-pages` 保留 HTML，浏览器手动打开看；注意路径不能有中文以外的奇怪字符 |
| `截图尺寸异常：期望 2304x3072，实际 …` | `--scale` 与窗口尺寸不匹配，或页面里图片加载失败 | 先看 HTML 里的相对路径是否都在 `work/` 下 |
| `导出 PDF 失败` | 页面用 `@page size` 之外的尺寸 | 只影响 PDF，图片仍是好的；可先用图片交付 |
| `Python 版本` 报红 | 低于 3.8 | 换解释器，不要改代码凑合 |

## 网络 / 接口类

| 现象 | 原因 | 处理 |
|---|---|---|
| `队列已满` / `queue_full` | 服务端并发 8，满了 | 脚本按 `estimated_wait_seconds` 自动退避；频繁出现就错峰跑 |
| `服务端 CPU 过载`（429） | 服务端忙 | 同上下，重试会退避 |
| `提交失败 HTTP 400：Missing  fontfile.` | 传进去的不是真实 ttf 名（底层接口纯字符串精确匹配） | 用 `--font 一号字体` / `--font 二号字体` 走脚本换算；`hw.py fonts` 看对照表 |
| `The text is too long to process` | 单题文本过长 | 拆成两道题，或删减内容 |
| `渲染超时（300s）` | 排队太久 | 加大 `--jobs` 无助于接口；等一会儿重跑（页图有断点，会跳过已完成的） |
| `接口不可用` | 断网 / 站点宕机 | `--offline` 只能跑拆块和排版，渲染必须联网 |

## 内容类

| 现象 | 原因 | 处理 |
|---|---|---|
| `标签行数不匹配：需要 N 个，切出 M 行` | 标签字条被服务端重新折行/合并了 | 脚本已按固定行距 `SHEET_LS` 把切碎的带归并回 N 行（笔锋断墨不再误判）。仍报错说明服务端真的合并或折行了：把过长标签改短，或减少该图标签数量。这是硬失败，不放行 |
| 文字挤成一团 / 溢到图里 | `budget` 偏大，服务端又折了一次导致行数变多 | 把 `budget` 调小 0.5~1；改完先跑 `render` 再 `extract` |
| 图上出现穿过图形的横线 | 横线判据太松（把坐标轴当线了） | 确认判据是 `>0.80×页宽`；坐标轴最宽只占 67% |
| 文字块里出现莫名其妙的横线 | 辅助线没剔干净 | 看 `meta.json` 里的 `rules` 条数，正常应等于文字行数；异常时调 `DARK` |
| 成品里图形被切掉一角 | 用了固定框裁图而不是包围盒 | 检查 `stage_extract.one()` 是否走 `imgfit.bbox` |
| 纸面上的字被抹掉了 | 擦线算法把墨迹当横线 | `--clean-lines off` 重跑 `paper` |

## 版式类

| 现象 | 原因 | 处理 |
|---|---|---|
| 页数比预期多 | 字号缩放下限 `SMIN` 顶到 0.30 | 减少每页题数（`layout.per_page`）或调小 `SMIN` |
| 字号忽大忽小（跨页不一致） | 每页独立算缩放 | 这是刻意的（自适应）；要统一就固定 `layout.per_page` |
| 图太小 | 图宽上限 `0.326W` / 图高上限 `1.22×文字块` | 在 job 里给该图 `"size"`，或调 `stage_layout.FIG_H_RATIO` |
| 右侧留白太多 | 该题没有配图 | 正常；也可用 `figure_side: "below"` 让文字占满宽度 |

## 缓存类

| 现象 | 原因 | 处理 |
|---|---|---|
| 改了文字但成品没变 | `work/pages/qN.png` 被当成已完成 | `--force` |
| 改了产物尺寸没生效 | 纸面 `paper.json` 被复用 | `--force`，或删掉 `work/` |
| 只想调排版 | 拆块结果没变 | 直接 `hw.py layout --job ...`，会命中缓存 |
