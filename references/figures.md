## 覆盖范围

这套图面向《生产与成本理论》一类题型（生产函数、成本函数、规模报酬）。换学科通常要新增图。

## 规格覆盖

单张图想改尺寸，在 job 里写：

```json
{ "figures": [ { "name": "tp_mp", "size": [1180, 900] } ] }
```

画布宽高变了，内部坐标会自动重算；标签位置跟着走，不用手改。

## 用自己的图

```json
{ "figures": [ { "file": "C:/my/own.png", "size": [900, 700] } ] }
```

- 图片要求：白底、深色线条（深于灰度 176），贴到纸上时白底会被抠掉
- `size` 是它在页面上的像素尺寸（2481×3507 的画布下），省略时尝试读 PNG 头
- 自己的图不会加手写标签，需要的话先用图片编辑工具画好

## 新增一张图

1. 在 `figures.py` 里写一个 `def fig_xxx(w=980, h=680)`：内部用 `H(w, h, xmax, ymin, ymax, seed=…)` 建坐标系，`p.axes("Q")` 画轴，`p.curve(f, x0, x1, lw=7.5)` 画线，`p.text(x, y, "标签")` 记标签坐标（**不会真的画字**，由手写贴片替代）
2. 在文件末尾的 `REGISTRY` 里加一行：`"xxx": (fig_xxx, 980, 680, "一句话说明")`
3. `python hw.py build` 里用 `"figures": ["xxx"]` 试跑，看图是否完整、标签有没有错位

注意：
- 每张图都会额外消耗 **1 次**手写接口调用（用来生成标签字条），所以标签别太多
- `text()` 记的 `size` 决定贴片大小（44~50 比较合适）；`anchor` 支持 `start/middle/end`
- 抖动是伪随机的（按 `seed`），同一张图每次输出完全一致，方便回归比对
